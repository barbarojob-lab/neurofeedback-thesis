# neurofeedback-thesis

Repositorio de la tesis sobre neurofeedback. Contiene la implementación, experimentos y documentación asociados al proyecto.

Descripción

Este proyecto recoge el código y los resultados utilizados en la tesis de investigación sobre neurofeedback. Incluye el procesamiento de señales, la interfaz para la adquisición de datos, los experimentos y los scripts para análisis y visualización.

Contenido principal

- /src — Código fuente (adquisición, procesamiento, análisis)
- /data — Conjuntos de datos y resultados (si aplica, puede contener resultados resumidos; NO incluir datos sensibles)
- /notebooks — Jupyter / notebooks con análisis y visualizaciones
- /docs — Documentación adicional y metodología

Objetivos

- Implementar y evaluar métodos de neurofeedback
- Reproducir experimentos y generar figuras para la tesis
- Proveer scripts para preprocesamiento y análisis estadístico

Tecnologías

- TypeScript / JavaScript (si aplica)
- Python (NumPy, SciPy, MNE, pandas, matplotlib) — ajustar según el contenido real
- Herramientas de procesamiento de señales y machine learning (scikit-learn, PyTorch, etc.)

Requisitos

- Python 3.8+ (si hay scripts en Python)
- Node.js 16+ (si hay partes en TypeScript/JS)
- Dependencias listadas en requirements.txt o package.json cuando apliquen

Instalación rápida

1. Clona el repositorio:

   git clone https://github.com/barbarojob-lab/neurofeedback-thesis.git
   cd neurofeedback-thesis

2. Instala dependencias (ejemplo para Python):

   python -m venv venv
   source venv/bin/activate  # Linux / macOS
   venv\Scripts\activate     # Windows
   pip install -r requirements.txt

3. Ejecuta notebooks o scripts según la carpeta /notebooks o /src.
